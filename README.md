# Bibliometric Analysis of Metabolic Liver Disease Research in the Arab World

This repository contains the R code for the analysis of the paper "Metabolic liver disease research in the Arab world: a bibliometric analysis of trends, collaborations, and disparities (2006-2024)".

El-Shabrawi MH, Suoh M, Almuhaidib S, Alqahtani SA, Al Awadhi S, Al-Busafi SA, Abdulla M, Fouad Y, Akroush M, Tahiri M, Altarrah MY, Eslam M. Metabolic liver disease research in the Arab world: a bibliometric analysis of trends, collaborations, and disparities (2006-2024). Minerva Gastroenterol (Torino). 2026;72(1):37-50. doi: 10.23736/S2724-5985.25.03949-X.
